# Guide Me

The researcher remembers one phrase. **They lead; you suggest.** Never start a skill on your own.
```
Stage: idea testing. Needs attention: your intro is out of date (the question changed Tuesday).
Top tasks: try two pilot versions · decide participant count · plan analysis
Suggested: /update-paper intro (about 20 min). Or: /plan-method pilot
Which one, or something else?
```

## 1. Look
- No project → suggest `update-repo`. No board → `update-board`.
- Read `current_status.md`, the board, latest `log.md`, `terms.md`.
- **Behind?** Suggest `update-repo` first if: no `full update` in `log.md` for 7+ days, results or reviews newer than the paper, `⚠ stale` rows, or an `AGENTS.md` without "Quick sync".
- First time or "what can you do?" → show `references/skills.md`.

## 2. Suggest (one skill + up to two others, then wait)
**You drive:** the top ticket and the skill for it. **Let me lead:** show the top 3 tickets and wait.

| Situation | Suggest |
|---|---|
| Thoughts still in their head | `brain-dump` |
| Suspects overlap; "is this novel?"; a paper they found; results contradict the idea | `update-paper` |
| What to change and measure, participants, pilots, runs | `plan-method` |
| Writing: the story, a section, stats, figures, reviewer replies | `update-paper` |
| Draft changed; citations; "can I submit?" | `review` |
| Recap, forgotten or messy tasks | `update-board` |
| Files or paper behind the latest work | `update-repo` |
| Not happy with what was proposed; wants other paths | `think-deeply` |
| One answer too technical / still lost | `clarify` / `teach-me` |
| Wants Chaky to always talk simpler, in their language | add it to `preferences.md` ("always...") |
| Writing voice / AI models and labeling | `setup-writing-style` / `plan-method` |
| Anything ⚠ stale | fix it first |

## 3. Modes (`references/modes.md`)
**Show progress** · **Advisor update** · **Retro**.

## 4. Close the session
Run the quick sync in `AGENTS.md` for the whole session. One mindset nudge (rotate, never nag). "Guide me" picks up here next time.

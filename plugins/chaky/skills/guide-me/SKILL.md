# Guide Me

The researcher remembers one phrase. **They lead; you suggest.** Never start a skill on your own.
```
Needs attention: your intro is out of date (the question changed Tuesday).
Top tasks: try two pilot versions · decide participant count · plan analysis
Suggested: /write intro (about 20 min). Or: /plan-method pilot
Which one, or something else?
```

## 1. Look
- No project → suggest `update-repo`. No board → `update-board`.
- Read `current_status.md`, the board, latest `log.md` and `review.md`, `terms.md`.
- Older `AGENTS.md` without "Change, then tell", or the paper behind the latest results? Suggest `update-repo`.
- First time or "what can you do?" → show `references/skills.md`.

## 2. Suggest (one skill + up to two others, then wait)
**You drive:** the top ticket and the skill for it. **Let me lead:** show the top 3 tickets and wait.

| Situation | Suggest |
|---|---|
| Thoughts still in their head | `brain-dump` |
| "Is this novel or good?"; results contradict the idea | `validate-idea` |
| Closest work, a method to borrow, a paper they found, scoop worry | `find-papers` |
| What to change and measure, participants, pilots, runs | `plan-method` |
| A section, stats, a figure, robotic text | `write` |
| Draft changed; citations; "can I submit?" | `review` |
| Recap, forgotten or messy tasks | `update-board` |
| Files or paper behind the latest work | `update-repo` |
| Not happy with what was proposed; wants other paths | `think-deeply` |
| Too technical, needs context or an example / still lost | `clarify` / `teach-me` |
| Voice, models, keys, free AI chats | `setup-writing-style`, `setup-llms` |
| Same instruction twice | `remember-this` |
| Anything ⚠ stale | fix it first |

## 3. Modes (`references/modes.md`)
**Show progress** · **Advisor update** · **Retro**.

## 4. Close the session
Run the end-of-task routine in `AGENTS.md`. Close tickets whose done-when is met; add new work as tickets. One mindset nudge (rotate, never nag). "Guide me" picks up here next time.

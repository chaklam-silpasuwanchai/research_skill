# Seed board (created at the end of onboarding)

Chaky assigns each priority (rules in `plan-tickets`); the researcher can change any. Edit names to match their topic.

| Ticket | Type | Pri | Blocked by | Done when |
|---|---|---|---|---|
| `terms` | decide | 3 | none | `terms.md` holds the 5 key domain terms, each with a one-line example |
| `refine-idea` | decide | 5 | none | one-sentence contribution; gap test passed |
| `closest-work` | read | 5 | none | about 20 verified papers; closest three compared |
| `first-draft` | write | 4 | `refine-idea` | title, abstract, introduction, related work drafted and checked by the researcher |
| `pilot-options` | try | 3 | `refine-idea` | three candidate pilots sketched; one chosen |
| `ethics-approval` (CHI) or `model-access` (NLP) | make | 5 or 3 | none | approval recorded before recruiting, or models and keys tested |
| `first-review` | check | 2 | `first-draft` | a review checkpoint run; Major fixes ticketed |

Fog: anything the researcher mentions but can't yet specify (sample size, analysis plan, follow-up study).

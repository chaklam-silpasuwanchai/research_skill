# Done-when defaults (edit per ticket; 1-3 checks each)

| Type | Default checks |
|---|---|
| **read** | about 20 verified papers; 1-5 key papers named; the closest three compared on problem, IV, DV |
| **decide** (idea) | one-sentence contribution; gap test passed; falsifiable hypotheses; the researcher says "I could defend this" |
| **decide** (plan) | IVs, DVs, baselines, analysis written down; `plan-freeze` tag set before main runs |
| **try** | pipeline or procedure ran end to end (or with 3 people); the DV moved or the failure is explained; logged |
| **make** | tests pass; one-command rerun works; for ethics: approval recorded |
| **write** | section drafted; `polish-prose` done; `review-paper` checkpoint passes every test for that section |
| **check** | no 🔴 fails (full mode), or every Major fix is a ticket |

**Time boxes:** S ≈ 1 hour · M ≈ 1 session · L → split before starting.
**Over the box?** Ask: split it, park it, or accept what we have?

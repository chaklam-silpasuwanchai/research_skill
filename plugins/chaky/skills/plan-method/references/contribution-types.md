# Contribution type decides what you must show
| Type | Implementation must show |
|---|---|
| **Empirical** | Clear hypotheses, IVs, DVs, controls; fair baselines; adequate sample; analysis plan fixed in advance |
| **Design** | Rationale from theory or prior work; working prototype; evidence it works vs a sensible alternative |
| **Artifact** (dataset, tool, benchmark) | Quality checks, documentation, validation that it measures what it claims, evidence others can use it |
| **Theoretical** | Precise definitions, logical argument, grounding in existing work, tests on concrete cases |

Record the type in `experimental_design.md` and `current_status.md`.

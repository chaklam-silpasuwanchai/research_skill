# Think Deeply

Use when the researcher isn't satisfied with what was proposed. One question: **is there a better path than this?** "This" = the latest message, or what they name.

1. **Restate** the problem and the solution in one sentence each.
2. **360° views** (a line each): reviewer at the venue · participant or data · advisor · skeptic (boring explanation, strongest counterexample) · practitioner · ethics and risk.
3. **First principles:** the real goal underneath; the simplest thing that meets it.
4. **Assumptions:** 2-4 the solution rests on; true here? Pick the one that matters most.
5. **Go deep** on it: ask "why?" until it is checkable, then check (repo, paper, number).
6. **Systems:** what else it touches; what happens next, and after that.
7. **Propose the most sensible approach.** Compare 2-3 genuinely different paths (not small tweaks) on: meets the real goal · evidence behind it · risk to validity · time and cost · fits the deadline and venue. Pick the one that wins overall, which may be a mix of paths or the current plan.

## Answer
```
Goal underneath: ...
Worried views: reviewer (...), skeptic (...)
Weakest assumption: ... → checked: ...
Knock-on effects: ...
Paths: A (current) gains ... costs ... · B ... · C ...

✅ Recommended approach: <one sentence>
Why it's the most sensible: <2-3 reasons from the comparison>
Steps: 1 ... 2 ... 3 ...
First step now: <a concrete action, with the skill if one fits, e.g. /plan-method DV>
Would change my mind: <the evidence that would make another path better>
Go with this, or another path?
```
Always end with one clear recommendation, not a menu. If the current plan is best, say so and recommend keeping it. Never present a guess as a finding. If they choose a new path, end with the quick sync in `AGENTS.md`.
